# MyKehila Privacy Policy

This repository hosts the Privacy Policy for **MyKehila**.

MyKehila is a community app designed for Jewish communities worldwide. It provides community announcements and events, Shabbat and candle-lighting times, Torah content, Jewish calendar information, prayers, learning resources, and community services.

No sign-in is required to use the app.
